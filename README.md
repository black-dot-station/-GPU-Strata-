# 他人のGPUで食うStrataはうまい。

自分のRunPodアカウントでGPUを借りて、Ubuntuのデスクトップから使えるアプリです。GPUの空き状況、1時間あたりの料金、予約、起動・停止をひとつのウィンドウで操作できます。RTX 3090 Tiでは「AIセットアップ」から本家StrataとQwenを接続できます。

## インストール

1. このリポジトリの **Releases** を開き、v1.2.2の **Assets** から `runpod-gpu-desktop_1.2.2_all.deb` をダウンロードします。
2. ダウンロードしたフォルダーで、次のコマンドを実行します。

   ```sh
   sudo apt install ./runpod-gpu-desktop_1.2.2_all.deb
   ```

3. アプリ一覧から **RunPod GPU マネージャー** を開きます。デスクトップ環境にはGTK 4.12以降、WebKitGTK 6.0、GNOMEキーリングとsystemdのユーザーセッションが必要です。AIセットアップが取得するStrataはLinux x86-64版です。

## 最初のGPUを借りる

- 初回は「案内を始める」か「スキップ」を選べます。メニューの「初めてGPUを借りる」からいつでも再表示できます。
- 自分のメールアドレスでRunPodの本人確認を済ませるか、Podsの読み書き権限を持つ自分のAPIキーで接続します。キーはこのPCのキーリングに保存されます。
- 「GPU一覧・予約」で機種と料金上限を選びます。○は「今すぐ起動」、×は「予約して自動起動」です。残高が必要な場合は「RunPodの支払い設定」を開けます。
- 使い終わったら「メニュー」→「Podの電源・状態」→「停止」を押し、停止状態を確認します。**サインアウトしても、稼働中のPodの課金は続きます。**

## ソースからパッケージを作る

Python 3と `dpkg-deb` を用意し、リポジトリのルートで `python3 build_deb.py` を実行すると、`dist/` にインストール用のパッケージができます。
